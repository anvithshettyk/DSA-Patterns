# 📝 Strings

## 📖 Description

String problems involve processing, modifying, and analyzing sequences of characters using techniques such as traversal, simulation, hashing, two pointers, stacks, and pattern matching.

---

## 💡 Key Idea

- Traverse the string efficiently.
- Use appropriate data structures when needed.
- Carefully handle edge cases.
- Optimize space and time whenever possible.
